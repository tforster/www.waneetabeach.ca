# Cloudflare Pages for hosting

**Date:** 2026-05-11 **Status:** Accepted

The project needs reliable, low-cost global hosting suitable for a small community association. Decided to deploy to Cloudflare Pages, serving static assets from the global Cloudflare CDN with a generous free tier.

## Consequences

- Zero server management
- Automatic HTTPS and custom domain support
- Workers can be added later for the members message board API
